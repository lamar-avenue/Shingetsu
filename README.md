# Маша × Марк — наша первая глава

Короткий интерактивный фильм: настройки → слова и моменты → три конверта → шахматный этюд → финал.
После одного нажатия фильм воспроизводится автоматически. Есть пауза, перемотка,
повтор и продолжение с сохранённого времени. Настройки и прогресс хранятся только
в браузере. При уходе на другую вкладку фильм приостанавливается.

## Запуск
Откройте `index.html` в современном браузере. Сборщик и зависимости не нужны.
Сохранение localStorage надёжнее при открытии опубликованного сайта, чем file://.

## Содержание и озвучка
`content.js` — единый монтажный план: реплики, интервалы, озвучка и фото.
Текущая черновая длительность — 116 секунд плюс время открытия конвертов. Настоящая озвучка ещё не предоставлена.
Чтобы подключить её, добавьте аудиофайл в `assets`, укажите путь в `narration`
и подгоните `start`/`end` реплик под запись. При наличии записи её currentTime
становится источником времени для текста, доски и фотографий. Пауза и перемотка
синхронизированы. Без записи история идёт по монтажному таймеру.

Добавьте реальные фотографии в `assets` и массив `photos`:
`{ src: 'assets/photo-01.jpg', caption: 'Реальная подпись' }`.
В финале фото меняются с интервалом 1.2 секунды и плавно перекрываются;
в спокойном режиме интервал не менее 3.5 секунды. Отсутствующие фото не
подменяются выдуманными лицами: до получения материалов остаётся вечерний фон.
Тексты вне утверждённой шахматной сцены — черновые и требуют личных слов Марка.

## Шахматы
Это постановочный этюд, не записанная партия и не дебют.
Конь f3 → h4 оказывается на диагонали чёрного ферзя d8. Пауза подчёркивает
сожаление, затем конь находит продолжение h4 → f5, а ферзь d1 → f3 поддерживает
его. Ходы служат контексту текста; нет победителя, соперничества пары и отката
времени. Положение фигур вычисляется по времени фильма, включая перемотку.

## Публикация и проверка
`python scripts/prepare-static.py` — подготовить только публичные ресурсы в dist.
`node --test tests/timeline.test.cjs` — границы сцен, перемотка, финал, скорость фото.
`node --check app.js` — проверить синтаксис.

Фон `assets/evening.webp` сгенерирован для атмосферы, не является личной фотографией.
Фоновая музыка — оригинальная lo-fi петля 72 BPM: мягкие клавиши, бас и негромкий ритм. Это не голос Марка. Источник: assets/lofi-evening.mp3.

Конверты останавливают монтаж на 28-й секунде до открытия трёх сюрпризов; музыку можно оставить включённой. После открытия история продолжится сама; конверты также можно пропустить. При перезагрузке открытые конверты сохраняются, при полном повторе сбрасываются. Тексты сюрпризов — творческие заготовки, без выдуманных воспоминаний.

Зерно удалено. Четыре атмосферы меняют освещение фонового изображения и всю палитру: ночь, янтарь, сиреневые сумерки, светлое утро.


## Последние изменения
- Верхняя надпись удалена; у шапки и финала общий непрерывный фон.
- Громкость (0–100%) регулируется сверху и в настройках, значение сохраняется.
- Анимации включены по умолчанию; системное «уменьшение движения» учитывается автоматически.
- Темп истории и будущей озвучки — 1.15×. Музыкальная петля играет в исходном темпе.
- Монтажный таймлайн — 116 секунд, просмотр занимает примерно 101 секунду плюс открытие конвертов.

## Загрузка на GitHub
Распакуйте ZIP и загрузите содержимое в корень репозитория через Add file → Upload files.
Сохраните структуру папок assets, scripts и tests. index.html должен оказаться в корне.
Архив не включает историю Git, личные настройки окружения и служебную привязку Sites.
Для локального просмотра откройте index.html. Для GitHub Pages можно использовать корень ветки main.
