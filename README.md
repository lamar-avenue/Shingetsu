# Shingetsu

Shingetsu is a polished static interface prototype built around a new moon
workspace: quiet planning, animated ambience, lunar phase controls, and a
focused viewing mode.

## Run

Open `index.html` in a browser. No build step or dependency install is required.

## Structure

- `index.html` - application shell and controls
- `src/styles.css` - responsive visual design and CSS animations
- `src/app.js` - canvas sky animation and interaction logic

## Interaction Notes

- Use the illumination slider to change the moon phase.
- Switch the sky tempo between still, drift, and pulse.
- Toggle constellations and moon glow independently.
- Use focus view for a quieter full-screen composition.
