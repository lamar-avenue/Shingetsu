# Маша × Марк

Распакуйте архив и загрузите ВСЕ файлы в корень репозитория, заменив старые. Папки не нужны. Сам ZIP загружать не нужно.

index.html, стили, скрипты, MP3 и три MP4 должны лежать рядом. После обновления нажмите Ctrl+F5. Локально сайт можно открыть через index.html.

Фон встроен в styles.css. Содержание и тайминги — content.js; шахматная сцена — chess-scene.js; интерфейс и воспроизведение — app.js.
